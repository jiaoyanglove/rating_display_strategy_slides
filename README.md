# 同类产品评论展示策略研究 - 答辩演示文稿

本科毕业论文答辩 Beamer 演示文稿。

## 论文信息

- **题目**：同类产品评论展示策略研究：基于消费者学习的分析
- **作者**：焦洋
- **学校**：上海科技大学
- **日期**：2026年6月

## 核心结论

1. **聚合展示降低信息精度**：引入"评论来源不确定性"，消费者学习效率降低
2. **分开展示普遍占优**：对称情形下信息效率 2:1，所有测试参数下均占优
3. **利润与福利目标一致**：分开展示同时最大化利润、消费者剩余和社会福利
4. **评论精度非对称性强化结论**：精度差异越大，分开展示优势越明显

## 编译方式

### 本地编译

需要安装完整的 TeX Live 发行版（含中文支持）：

```bash
# macOS
brew install --cask mactex

# 编译（2-3次以确保交叉引用正确）
xelatex main.tex
xelatex main.tex
```

### Overleaf 导入

1. 直接导入本仓库 URL 到 Overleaf
2. 在 Overleaf 项目设置中选择 **XeLaTeX** 编译器
3. 点击编译
